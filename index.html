J#

A statically typed JVM language with C#'s expressiveness and Java's ecosystem. Beta.

Install the command line

Windows (PowerShell):

irm https://matrixidot.github.io/J-Sharp/install.ps1 | iex

macOS and Linux:

curl -fsSL https://matrixidot.github.io/J-Sharp/install.sh | sh

Java is included. Then: jsharp new app my-app (jsharp new --list shows the templates).

Editors

IntelliJ IDEA and VS Code plugins are on the releases page.

Gradle

// settings.gradle.kts
pluginManagement {
    repositories {
        maven("https://matrixidot.github.io/J-Sharp/maven")
        gradlePluginPortal()
    }
}

The Maven repository is at /maven. Source, documentation and license (Apache-2.0): github.com/matrixidot/J-Sharp.

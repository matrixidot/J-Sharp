# Showcase

A short tour of J# in one program: records with operators and properties, sealed types with
exhaustive switches and property patterns, collection literals, sequences with functions passed
by name, null safety, list patterns, local functions, atomic variables updated from virtual
threads, and extension methods.

`showcase.jsharp` has the top-level statements; `shapes.jsharp` is a library file it uses.

```
jsharp run examples/showcase/src
```

In VS Code, open `showcase.jsharp` and press ▶ Run (above the first statement or in the
editor's title bar).
